# 🌿 Schulte Verpackungs-Systeme GmbH

**Die Packmittel-Profis.**

Professionelle Website für Schulte Verpackungs-Systeme GmbH – Ihr Spezialist für Paletten, Kisten, Schwergutverpackungen und maßgeschneiderte Packmittelkonzepte seit über 100 Jahren.

## 🚀 Live Demo

Lokal ausführen:
```bash
python3 -m http.server 8000
```
Dann öffnen: `http://localhost:8000`

## ✨ Features

- **Responsive Design** – Mobile, Tablet, Desktop
- **Moderne UI** – Grün-Gold Farbschema (CO₂-neutral & Premium)
- **Animationen** – Scroll-Animationen, Counter, Hover-Effekte
- **SEO-optimiert** – Meta-Tags, Open Graph, Canonical
- **Barrierefreiheit** – ARIA-Labels, Skip-Link, semantisches HTML
- **Kontaktformular** – Mit Validierung und Erfolgsmeldung
