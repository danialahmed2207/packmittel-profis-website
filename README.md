# 🌿 Schulte Verpackungs-Systeme GmbH

**Die Packmittel-Profis.**

Professionelle Multi-Page-Website für Schulte Verpackungs-Systeme GmbH – Ihr Spezialist für Paletten, Kisten, Schwergutverpackungen und maßgeschneiderte Packmittelkonzepte seit über 100 Jahren.

## 🚀 Live Demo

Lokal ausführen:
```bash
python3 -m http.server 8000
```
Dann öffnen: `http://localhost:8000`

## 📁 Seitenstruktur

| Seite | Beschreibung |
|-------|-------------|
| `index.html` | Startseite mit Hero, Leistungen, Produkte, Prozess, Qualität, Export, Nachhaltigkeit, Karriere-Teaser, Kontakt-Teaser |
| `leistungen.html` | Alle 12 Leistungen im Detail + Prozessdarstellung |
| `produkte.html` | Produkte: Kisten, Paletten, Sonderpaletten, Schwergut, Mehrweg, Kombiverpackungen |
| `branchen.html` | Branchenlösungen für 8 Industriezweige |
| `qualitaet-export.html` | Qualitätsmanagement, IPPC/ISPM 15, Exportverpackungen |
| `nachhaltigkeit.html` | Nachhaltigkeit, Recycling, Mehrweg, CO₂-Bewusstsein |
| `karriere.html` | Stellenangebote mit Filter, Benefits, Bewerbungsformular |
| `kontakt.html` | Kontaktformular, Ansprechpartner, Karte |
| `impressum.html` | Impressum |
| `datenschutz.html` | Datenschutzerklärung |
| `agb.html` | Allgemeine Geschäftsbedingungen |

## ✨ Features

- **Multi-Page Architektur** – 11 vollständige HTML-Seiten
- **Responsive Design** – Mobile, Tablet, Desktop
- **Moderne UI** – Grün-Gold Farbschema (Nachhaltigkeit & Premium)
- **Animationen** – Scroll-Animationen, Counter, Hover-Effekte
- **SEO-optimiert** – Meta-Tags, Open Graph, Canonical, klare H-Struktur
- **Barrierefreiheit** – ARIA-Labels, Skip-Link, semantisches HTML
- **Kontaktformular** – Mit Validierung, Datei-Upload, DSGVO-Checkbox
- **Bewerbungsformular** – Karriere mit Job-Filter und Datei-Upload
- **Cookie-Banner** – DSGVO-konform mit localStorage
- **Job-Filter** – Filterung nach Kategorien (Produktion, Logistik, Vertrieb, Ausbildung, Quereinstieg)
